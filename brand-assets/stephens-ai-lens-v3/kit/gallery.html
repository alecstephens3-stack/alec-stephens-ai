Six ways to show the argument.

The system had surfaces and markers but no information structures. These six are the structures: a way to show a change, a calculation, a protocol, a position, a sequence, and an idea. Every one carries a night variant. Copy the markup from here, never rebuild it.

03 · Decision path

Front desk: booking a post-op co-manage

A rail with lens beads. Linear steps for "how it runs", a fork where the answer depends on something. This is the protocol primitive: condition, route, outcome.
STEP 01

Confirm the surgery date and the operating surgeon

Co-management windows are counted from the procedure, not from the referral. Get both before anything goes on the schedule.

STEP 02 · DECISION

Which payer is primary?

This one answer changes the visit type, the billing code, and how far out you are allowed to book.

If commercial
Book into the standard post-op slot. No prior auth needed inside the 90-day global period.
If KanCare
Route to the co-manage visit type, not the standard post-op. Attach the surgeon's referral before the appointment is saved.
ConfirmRule pending Gabe's sign-off
If self-pay
Quote from the posted fee schedule and collect at check-in. Do not apply the global-period discount.
STEP 03 · DONE

Note the co-managing surgeon in the appointment comment

The doctor reads this comment before walking in. Missing it is the single most common reason a co-manage visit runs long.

How to use the kit

One line instead of a hundred and fifty

The workflow

Put the SAI:KIT marker comment in the head, then run python3 scripts/inline_kit.py your-file.html. Re-run it any time the kit changes and every artifact picks up the update.

  • Never hand-copy the CSS. An approximated lens gradient reads as a grey smudge, and the hand-written version drifts from the system the moment the system changes.
  • Markers, not just the kit. SAI:SCENE emits the sky and five drifting lenses, SAI:LOGO emits the canonical mark. Both are things that used to get rebuilt wrong.
  • One night window per light page. The claim cards above are this page's. Every widget has a night variant, but restraint is what makes it land.
  • Screenshot-QA before delivering. Non-negotiable, unchanged.
Bench: Anatomy Diagram (numbered portholes pinned to a screenshot) and Tier Compare (the rung ladder) are specced but not built. Say the word.
